# 好看电视

好看电视是一款简洁的网络视频直链播放器。你可以粘贴公开可访问的视频 URL，在 iPhone 或 iPad 上直接播放。

本 App 不提供、搜索、推荐、解析、下载、聚合或托管任何视频内容。

## 主要功能

- 播放 HLS（`.m3u8`）、MP4、MOV 等 iOS 支持的视频格式
- 保存播放历史和播放进度
- 收藏和重命名视频链接
- 点击或拖动进度条跳转
- 调整播放速度
- 循环播放
- 全屏横屏播放
- 画中画和后台播放
- 深色模式
- 所有历史、收藏和设置均保存在设备本地

## 使用方法

1. 复制公开可访问的视频直链。
2. 打开“好看电视”。
3. 点击“粘贴”填入视频地址。
4. 点击“播放”。

成功播放后，视频会自动加入历史记录。

## 链接要求

请输入以 `HTTP` 或 `HTTPS` 开头的视频直链。

普通网页地址通常不是视频直链。以下情况可能无法播放：

- 链接已经失效
- 视频格式不受 iOS 支持
- 视频需要登录或身份验证
- 视频受到 DRM 保护
- 服务器启用了防盗链
- 视频服务禁止第三方播放器访问
- 当前网络无法访问视频服务器
- 直播流暂时不可用

请仅播放你有权访问和使用的视频内容，并遵守适用法律、版权许可及内容提供方的使用条款。

## 数据与隐私

好看电视当前不提供账号、广告或分析服务。

播放历史、收藏、视频名称、播放进度和设置仅保存在用户设备本地。播放视频时，App 会直接连接用户提供的视频服务器。

详细说明请阅读：

- [隐私政策](https://yongzheng784-star.github.io/IOSVideoPlayer001/PRIVACY_POLICY.html)
- [用户协议](https://yongzheng784-star.github.io/IOSVideoPlayer001/USER_AGREEMENT.html)

## 数据删除

你可以通过以下方式删除本地数据：

- 在历史或收藏页面移除单条记录
- 在设置页面清空所有本地数据
- 从设备中删除 App

清空后的本地数据无法恢复。
