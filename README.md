# 好看电视链接播放

一个使用 SwiftUI 和 AVKit 编写的 iOS 网络视频播放器。

## 应用标识

- Bundle Identifier：`com.zhengyong.videoplayer`

## 功能

- 粘贴并播放 `http` / `https` 视频直链
- 支持系统原生可播放格式，如 HLS (`.m3u8`)、MP4、MOV
- 原生播放控制、全屏与画中画能力
- 无效 URL、网络错误和不可播放资源提示
- 可通过其他 App 的 URL 打开入口接收视频链接
- “播放 / 历史 / 收藏”底部导航
- 成功播放后自动保存历史，同一 URL 不会重复
- 本地保存播放进度，从历史或收藏中点击可继续播放
- 收藏、取消收藏、滑动移除与清空历史
- 清空历史时保留已收藏的视频
- 加载和缓冲状态、播放失败重试
- 0.5× 至 2× 倍速与循环播放
- 后台音频与系统画中画支持
- 历史和收藏支持搜索、重命名、复制链接与系统分享

## 运行

1. 用 Xcode 打开 `VideoPlayer001.xcodeproj`
2. 在项目的 Signing & Capabilities 中选择你的开发团队
3. 选择模拟器或真机后运行

> 视频网站的“网页链接”通常不是视频文件地址。需要使用公开可访问的视频流直链，并确保你有权访问和播放相关内容。
